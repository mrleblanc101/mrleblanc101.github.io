Bonjour, voici mon setup ultime pour configurer un nouveau Mac pour le développement Front-end !

Premièrement, vous allez vouloir installer [Homebrew](https://brew.sh/). Homebrew est un utilitaire de ligne de commande qui vous permettra d'installer toutes sortes d'autres outils essentiels :

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

iTerm 2 :
Nommer vos fenêtres et vos onglets
Installer un thème de couleur approprié, mon préféré est Solarized Dark.
`CMD + Click` sur un lien pour l'ouvrir directement dans votre navigateur par défaut.
Supporte parfaitement les glyphes Powerline pour un prompt personnalisé qui fait rêver !
Il ne vous reste qu'à installer Oh My Zsh et votre thème préféré.
Je recommande fortement p10k pour sa simplicité et sa facilité de personnalisation.

Oh My Zsh :
Double-cliquer sur du texte dans le terminal (Ex. le path vers un fichier) permet de le copier automatiquement dans le presse-papiers, ce qui facilite l'insertion dans une autre commande en cours d'écriture.
